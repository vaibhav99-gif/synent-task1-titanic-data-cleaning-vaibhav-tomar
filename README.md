# Titanic Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning and preparing the Titanic dataset using Python and Pandas. The objective is to improve data quality and make the dataset suitable for further analysis.

## Objectives
- Inspect the dataset and understand its structure.
- Identify missing values and duplicate records.
- Handle missing data appropriately.
- Check data types and improve data consistency.
- Verify the cleaned dataset.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Project Workflow
1. Load the Titanic dataset.
2. Inspect rows, columns, data types, and missing values.
3. Clean the dataset according to the selected preprocessing steps.
4. Verify the results after cleaning.
5. Review the cleaned dataset.

## Files
- `titanic_data_cleaning.ipynb` — notebook containing the code, explanations, and outputs.

## How to Run
1. Open the notebook in Google Colab.
2. Upload the Titanic CSV dataset if prompted.
3. Run the cells from top to bottom.

## Dataset
The Titanic dataset is available from the [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data).
